Connexion

GitHub Pages n'a pas de serveur : la connexion se fait avec ton nom d'utilisateur GitHub et un token d'accès personnel (qui joue le rôle de mot de passe). Le token reste uniquement dans ton navigateur, pour cette session — il n'est jamais écrit dans le dépôt.

Crée-le sur GitHub → Settings → Developer settings → Personal access tokens (Fine-grained), avec accès en lecture/écriture sur « Contents » pour ce seul dépôt.
